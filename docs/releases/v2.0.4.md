## v2.0.4 — ⌘C ⌘C 不再誤觸 | ⌘C ⌘C no longer fires by accident

### 繁體中文

- **修正：另一台 Mac 複製時，這台跳出 `⌘C ⌘C` 選單。** 透過「通用剪貼板」傳來的內容現在一律忽略。
- **修正：v2.0.3 後仍會誤觸。** 沒有「輔助使用」權限時，舊版會退回只看剪貼簿變動的判斷，仍會被複製按鈕、右鍵複製、遠端剪貼簿誤觸。現在 `⌘C ⌘C` 一定要偵測到兩次真的 `⌘C` 按鍵才會觸發；沒有權限就停用。
- **改善：授權後立即生效。** 不必重開 App。設定 →「⌘C ⌘C 快速傳送」會顯示是否已啟用，未啟用時有「開啟設定」按鈕。
- 更新後若仍顯示未啟用：macOS 可能讓舊授權失效（清單上看起來仍勾選），請在「系統設定 → 隱私權與安全性 → 輔助使用」把 Peekabrowser 移除（−）再重新加入（+）。
- 已安裝 v2.0.x 的使用者可以從「設定 → 更新」直接更新。

### English

- **Fixed: copying on another Mac opened the `⌘C ⌘C` picker here.** Items arriving through Universal Clipboard are now ignored.
- **Fixed: accidental triggers after v2.0.3.** Without Accessibility the old fallback still judged by clipboard changes alone, so copy buttons, menu copies and remote clipboard items could trigger it. `⌘C ⌘C` now always requires two real `⌘C` presses and is off without Accessibility.
- **Improved: takes effect as soon as Accessibility is granted**, no relaunch needed. Settings → "⌘C ⌘C Quick send" shows whether it is on, with an "Open Settings" button when it is off.
- If it still shows off after updating, macOS may have invalidated the old grant (it can still look checked): remove Peekabrowser (−) under System Settings → Privacy & Security → Accessibility and add it again (+).
- v2.0.x users can update from Settings → Updates.

### 安裝 | Installation

1. 下載 `Peekabrowser_2.0.4_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_2.0.4_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 雙擊 `Install.command`，或拖曳到「應用程式」| Open the DMG → run `Install.command`, or drag to Applications
3. 手動安裝時執行 `xattr -cr /Applications/Peekabrowser.app` | If installing manually, run `xattr -cr /Applications/Peekabrowser.app`
