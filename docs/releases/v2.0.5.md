## v2.0.5 — Apple 簽署與公證 | Signed and notarized by Apple

### 繁體中文

- **改善：通過 Apple 公證。** Peekabrowser 現在使用 Apple Developer ID 簽署並通過 Apple 公證（notarization），下載後可以直接開啟，不再出現「已損毀」或「未識別的開發者」警告，也不需要執行 `xattr` 指令。
- **改善：之後更新不會再讓「輔助使用」授權失效。** 以前每次更新後 macOS 可能把舊授權視為無效；從這版開始簽署身分固定，授權會保留。
- **這次更新需要重新授權一次：** 因為簽署身分改變，請在「系統設定 → 隱私權與安全性 → 輔助使用」把 Peekabrowser 移除（−）再重新加入（+）。「螢幕錄製」若有用到截圖功能也同樣處理。
- **修正：Intel Mac 的 OCR。** 內建的文字辨識程式改為同時支援 Apple Silicon 與 Intel。
- 已安裝 v2.0.x 的使用者可以從「設定 → 更新」直接更新。

### English

- **Improved: notarized by Apple.** Peekabrowser is now signed with an Apple Developer ID and notarized, so it opens right after download with no "damaged" or "unidentified developer" warning and no `xattr` step.
- **Improved: future updates keep the Accessibility grant.** Previously macOS could invalidate the grant after each update; the signing identity is now stable.
- **Re-grant once for this update:** because the signing identity changed, remove Peekabrowser (−) under System Settings → Privacy & Security → Accessibility and add it again (+). Do the same for Screen Recording if you use screenshots.
- **Fixed: OCR on Intel Macs.** The bundled text-recognition helper now supports both Apple Silicon and Intel.
- v2.0.x users can update from Settings → Updates.

### 安裝 | Installation

1. 下載 `Peekabrowser_2.0.5_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_2.0.5_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 拖曳到「應用程式」，或雙擊 `Install.command` | Open the DMG → drag to Applications, or run `Install.command`
