## v2.0.2 — 登入時自動啟動、介面語言統一 | Launch at login, one interface language

### 繁體中文

- **新增：「登入時自動啟動」**（設定 → 一般）。開啟後，登入 macOS 時會自動在背景啟動 Peekabrowser。
  - 使用使用者層級的 LaunchAgent（`~/Library/LaunchAgents/Peekabrowser.plist`），不需要額外權限，未簽章的 App 也能穩定運作。
  - 開關顯示的是系統的實際狀態：開啟設定頁或切回視窗時會重新讀取；App 被移動或更新後，下次啟動會自動修正登錄的路徑。
- **新增：介面語言切換**（設定 → 一般 → 介面語言）。預設為繁體中文，可改為 English，切換後即時生效、重開後保留。
  - 範圍涵蓋設定視窗、⌘C ⌘C 選單、紀錄視窗、行事曆／提醒事項快速建立視窗、側邊欄按鈕提示、選單列選單、通知與更新狀態訊息。
  - 統一用詞：Destination 一律稱為「目的地」。
- **改善：設定頁重新整理。** 分為「目的地／⌘C ⌘C 快速傳送／外觀與省電／快捷鍵／更新／一般」六組，開關改為 macOS 風格的切換鈕，間距、對齊與說明文字層級一致，深色模式照常跟隨系統。既有功能行為不變。
- 已安裝 v2.0.x 的使用者可以從「設定 → 更新」直接更新。

### English

- **New: Launch at login** (Settings → General). Starts Peekabrowser in the background when you log in to macOS. It uses a per-user LaunchAgent (`~/Library/LaunchAgents/Peekabrowser.plist`), which needs no extra permission and works for this unsigned app. The switch shows the actual system state, re-read whenever Settings opens or regains focus, and the registered path is refreshed at launch if the app was moved or updated.
- **New: interface language** (Settings → General → Language). Traditional Chinese by default, with English available; changes apply immediately and persist. Covers Settings, the ⌘C ⌘C menu, Records, the Calendar/Reminders quick-create window, sidebar tooltips, the menu-bar menu, notifications and update status messages. "Destination" is consistently 「目的地」 in Chinese.
- **Improved: Settings layout.** Six groups (Destinations / ⌘C ⌘C Quick send / Appearance & power / Keyboard shortcuts / Updates / General), macOS-style switches, consistent spacing and help text, and dark mode still follows the system. Existing behavior is unchanged.
- v2.0.x users can update from Settings → Updates.

### 安裝 | Installation

1. 下載 `Peekabrowser_2.0.2_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_2.0.2_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 雙擊 `Install.command`，或拖曳到「應用程式」| Open the DMG → run `Install.command`, or drag to Applications
3. 手動安裝時執行 `xattr -cr /Applications/Peekabrowser.app` | If installing manually, run `xattr -cr /Applications/Peekabrowser.app`
