## v2.0.0 — 自動更新、選單快捷鍵、一鍵傳送、圓角外觀 | Auto-update, picker shortcuts, one-step send, rounded corners

### 繁體中文

**🔄 自動檢查／安裝更新（新功能）**
- 啟動時與每天自動檢查 GitHub Releases；有新版本時通知，並在設定按鈕顯示紅點。
- 設定 → 更新：顯示目前版本與新版說明，一鍵「安裝並重新啟動」。
- 下載後會比對 GitHub 公布的 SHA-256、確認 App 識別碼與版本，再替換 App 並自動重新開啟；設定與登入資料都會保留。
- 可選「自動安裝更新」：只在側邊欄隱藏、沒有正在生成的回答時進行。選單列也新增「Check for Updates…」。
- 若 App 不在可寫入的位置（例如直接從 DMG 執行），會提示改用下載頁面手動更新。
- **從 v1.8.0 升級需要手動安裝一次**（v1.8.0 尚無更新功能），之後的版本就能自動更新。

**⌨️ 選單快捷鍵 C / V / B / N / M**
- `⌘C ⌘C` 彈出選單後，按 **C / V / B / N / M** 即可選擇前五個 Destination（依手指在底排的位置），`Esc` 關閉。
- 以實體按鍵判斷，**注音、拼音、日文等非英文輸入法下也能觸發**，而且按鍵會在輸入法處理之前被攔下，不會打出注音符號或干擾原本的 App。
- 選單上的每個 Destination 旁會顯示對應按鍵。

**⚡ 預設用第一個 Destination 開啟**
- 設定 → `⌘C ⌘C` 新增選項「預設用第一個 Destination 開啟」。勾選後 `⌘C ⌘C` 直接傳送到清單中的第一個 Destination，不再顯示選單。

**🔲 圓角外觀**
- 側邊欄與網頁視窗合成一個連續曲線（continuous corner）的圓角面板，貼合新版 macOS 的視窗弧度；只開側邊欄時四角皆為圓角。選單視窗也改為圓角，內部按鈕圓角同步調整。

**⚠️ 已知限制**
- 本版在 CI 完成編譯、單元測試與打包；自動更新的實際安裝流程、快捷鍵在各輸入法下的行為與圓角外觀尚未在實機驗證，歡迎回報。

### English

- **Automatic updates (new):** checks GitHub Releases at launch and daily, notifies (red dot on Settings), and installs with one click: the download is verified against GitHub's published SHA-256, the bundle identifier and version are checked, then the app is replaced and relaunched — settings and logins are kept. Optional fully automatic install (only while the panel is hidden and nothing is generating). "Check for Updates…" in the menu-bar menu. Updating from v1.8.0 needs one manual install; later versions update themselves.
- **Picker shortcuts:** after `⌘C ⌘C`, press **C / V / B / N / M** to pick the first five destinations, `Esc` to dismiss. Matching uses hardware key codes, so it works with non-English input methods (Zhuyin, Pinyin, Japanese…), and the key is consumed before the input method sees it.
- **Send to the first destination by default:** new setting — when on, `⌘C ⌘C` sends straight to the first destination without showing the picker.
- **Rounded corners:** the sidebar and page viewer form one continuous-curve rounded panel matching recent macOS windows (all corners rounded when the sidebar is alone); the picker is rounded too.
- Built, unit-tested and packaged on CI; the end-to-end update install, shortcut behavior across input methods and the corner look have not been verified on real hardware yet.

### 安裝 | Installation

1. 下載 `Peekabrowser_2.0.0_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_2.0.0_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 雙擊 `Install.command`，或拖曳到「應用程式」| Open the DMG → run `Install.command`, or drag to Applications
3. 手動安裝時執行 `xattr -cr /Applications/Peekabrowser.app` | If installing manually, run `xattr -cr /Applications/Peekabrowser.app`

設定、快捷鍵、查詢紀錄與網站登入狀態會保留 | Settings, shortcuts, records and website logins are preserved.
