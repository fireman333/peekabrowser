## v1.8.0 — 低耗能、可靠傳送、回答紀錄 | Low power, reliable delivery, saved answers

### 繁體中文

**🔋 待機降載**
- **不再整個 App 生命週期停用 App Nap。** 舊版啟動時使用的 `0x00FFFFFF` 等同 `NSActivityUserInitiated`，同時會阻止系統閒置睡眠。現在只有「本 App 發起、正在生成的 AI 回答」才持有活動 token（允許系統閒置睡眠），完成、失敗、取消、頁面卸載或 15 分鐘上限時釋放。
- **移除 16 ms 滑鼠輪詢。** 左緣顯示與自動隱藏改用滑鼠事件 + 一次性 300 ms 停留計時；螢幕配置變更時才更新幾何快取。可在設定中關閉「左緣顯示」，隱藏時就完全不監聽滑鼠（⌘⇧A 與選單列仍可用）。
- **移除 30 ms 剪貼簿輪詢。** 已授權「輔助使用」時由 ⌘C 按鍵事件觸發短暫取樣（只觀察、不攔截 ⌘C）；未授權時改為低頻取樣、偵測到變化才短暫加速。
- **Gemini 不再常駐每 3 秒讀整頁文字、每 10 秒 keep-alive**，也不會因回答內含 “An error occurred” 而重新整理、或因思考超過 30 秒就自動按停止。

**🗂 分頁與資源生命週期**
- 所有開頁／切頁／關頁統一經過同一個生命週期管理；同時最多 6 個已載入頁面，回收的視窗會先重用，不再無上限累積原生視窗。
- 隱藏一段時間（預設 5 分鐘，可設定）的背景頁面改為「可恢復卸載」：保留標題、網址與查詢關聯，點一下即回到原對話；生成中或有未送出草稿的頁面不會被卸載。
- 第 21 個分頁會正確釋放最舊頁面的資源（舊版只從清單移除）。
- 關頁不再清除整個網站的 Service Worker 與 Cache API；不再替換 `requestAnimationFrame`，背景媒體改用 WebKit 公開 API 暫停。

**📨 型別化傳送**
- 文字與截圖分開傳送：設定了 prompt 前綴的服務也能正確送出截圖（圖片 + prompt）。
- 等待頁面就緒後注入，成功即停止重試；每次查詢有 request ID，回收的同網域視窗也能傳第二、三次查詢，舊工作不會寫到新查詢。
- 只有圖片貼上未被接受時才嘗試拖放，避免重複附件。不支援圖片的服務（如 Google）自動改送 OCR 文字。
- 注入失敗時會提示並把內容放到剪貼簿，方便手動貼上。

**📝 查詢紀錄與保存回答（新功能）**
- 每次傳送都會在本機 SQLite 記下原文／截圖、完整 prompt、目的地與來源 App。
- 側邊欄「保存回答」按鈕或 `⌘⇧E`：擷取該頁對應查詢的回答（保留段落、程式碼區塊、表格、連結與 KaTeX 數學），並標示完整／生成中片段／無法判斷；有選取文字時只保存選取內容。重複保存會更新同一筆。
- 新的「紀錄」視窗：全文搜尋、收藏、標籤、筆記、重新開啟對話、複製／匯出 Markdown、刪除（連同截圖）。

**🎨 介面**
- 跟隨系統明暗模式；一致的線條圖示；按鈕依用途分組（保存／紀錄、導覽、更多、釘選／設定）。
- 頁面小圓點顯示標題與狀態（生成中、已卸載），並支援鍵盤操作與 VoiceOver 標籤。
- Picker 顯示原文摘要或截圖縮圖，可按 1–9 選擇。
- 原生材質：macOS 26+ 使用系統 Liquid Glass，macOS 13–15 使用 vibrancy；可在設定關閉改用純色。

**⚠️ 已知限制**
- 本版在 CI 上完成編譯、單元測試與打包；耗電數據、Liquid Glass 外觀與各 AI 網站的實際串流尚未在實機量測，歡迎回報。
- 網站改版可能讓某些服務的回答擷取失效；此時可先選取文字再保存。

### English

**🔋 Lower idle cost**
- **No more app-lifetime App Nap opt-out.** The old `0x00FFFFFF` value equals `NSActivityUserInitiated`, which also blocked idle system sleep. Now an activity token (that allows idle sleep) is held only while an AI answer started from Peekabrowser is generating, and is released on completion, failure, cancellation, page unload, or a 15-minute cap.
- **The 16 ms mouse poll is gone.** Edge reveal and auto-hide use mouse events plus a one-shot 300 ms dwell timer; screen geometry is cached and refreshed on display changes. Turning off "edge reveal" removes mouse monitoring while hidden.
- **The 30 ms clipboard poll is gone.** With Accessibility granted, ⌘C key events trigger a short sampling window (observe-only); otherwise sampling is low-frequency with a short fast window after each change.
- **Gemini no longer reads the whole page every 3 s or runs a 10 s keep-alive**, never reloads because an answer contains "An error occurred", and never auto-stops long reasoning.

**🗂 Page lifecycle**
- One lifecycle path for open/switch/close; at most 6 loaded pages, recycled windows reused first, so native windows no longer accumulate.
- Hidden background pages are unloaded after an idle time (default 5 min) but stay in the list with title, URL and query link — one click restores them. Generating pages and pages with an unsent draft are kept.
- Closing a page no longer wipes the site's Service Workers / Cache API; no more `requestAnimationFrame` monkeypatch.

**📨 Typed delivery**
- Text and screenshots are separate payloads, so screenshots work with prompt prefixes.
- Inject once the page is ready, stop on success; per-query request IDs; stale work can't write into a recycled viewer.
- Drag-and-drop is only tried when a pasted image wasn't accepted. Destinations without image input get OCR text.

**📝 Query records & saved answers (new)**
- Every query is stored locally (SQLite): original text or screenshot, full prompt, destination, source app.
- "Save answer" button / `⌘⇧E` captures the answer for that page's query as Markdown (paragraphs, code fences, tables, links, KaTeX) and marks it complete / partial / unknown; a selection is saved instead when present. Saving again updates the same record.
- New Records window: full-text search, favorites, tags, notes, reopen conversation, copy/export Markdown, delete (with its screenshot).

**🎨 UI**
- Follows light/dark mode; consistent line icons; grouped actions; page dots show title and state; keyboard/VoiceOver labels; picker preview and 1–9 keys; native Liquid Glass on macOS 26+ with vibrancy fallback on 13–15 (can be turned off).

**⚠️ Known limitations**
- Built, unit-tested and packaged on CI. Energy numbers, Liquid Glass appearance and live provider streaming have not been measured on real hardware yet — reports welcome.

### 安裝 | Installation

1. 下載 `Peekabrowser_1.8.0_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_1.8.0_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 雙擊 `Install.command`，或拖曳到「應用程式」| Open the DMG → run `Install.command`, or drag to Applications
3. 手動安裝時執行 `xattr -cr /Applications/Peekabrowser.app` | If installing manually, run `xattr -cr /Applications/Peekabrowser.app`

設定、快捷鍵與網站登入狀態會保留 | Settings, shortcuts and website logins are preserved.
