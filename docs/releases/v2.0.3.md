## v2.0.3 — 修正 ⌘C ⌘C 誤觸 | Fix accidental ⌘C ⌘C triggers

### 繁體中文

- **修正：`⌘C ⌘C` 快速傳送容易誤觸。** 先前只要剪貼簿在 0.5 秒內變動兩次就會跳出選單，因此以下情況都可能誤觸：
  - 點了網頁上的「複製」按鈕或右鍵選單複製後，接著按一次 `⌘C`
  - 某些 App 複製一次會寫入剪貼簿兩次
  - 按下 `⌘⇧C`、`⌘⌥C` 等其他快捷鍵，或按住 `⌘C` 不放
- 現在只要 Peekabrowser 有「輔助使用」權限，就必須在 0.5 秒內真的按兩次 `⌘C`（不含其他修飾鍵、不含按住連發）才會觸發。
- 未授權「輔助使用」時仍沿用剪貼簿時間判斷；建議在「系統設定 → 隱私權與安全性 → 輔助使用」開啟 Peekabrowser，授權後請重新開啟 App。
- 已安裝 v2.0.x 的使用者可以從「設定 → 更新」直接更新。

### English

- **Fixed: `⌘C ⌘C` quick send triggering by accident.** Previously any two clipboard changes within 0.5 s opened the picker, so a copy button or menu copy followed by one `⌘C`, apps that write the clipboard twice per copy, `⌘⇧C` / `⌘⌥C`, or holding `⌘C` could all trigger it.
- With Accessibility granted, it now requires two real `⌘C` presses within 0.5 s (no other modifiers, no key repeat).
- Without Accessibility it still falls back to clipboard timing. Enable Peekabrowser under System Settings → Privacy & Security → Accessibility, then relaunch the app.
- v2.0.x users can update from Settings → Updates.

### 安裝 | Installation

1. 下載 `Peekabrowser_2.0.3_aarch64.dmg`（Apple Silicon）或 `Peekabrowser_2.0.3_x64.dmg`（Intel）| Download the DMG for your Mac
2. 打開 DMG → 雙擊 `Install.command`，或拖曳到「應用程式」| Open the DMG → run `Install.command`, or drag to Applications
3. 手動安裝時執行 `xattr -cr /Applications/Peekabrowser.app` | If installing manually, run `xattr -cr /Applications/Peekabrowser.app`
